## 实现与部署

- 按用户提供的6页PDF增加1/5/20期诊断、各组多头/空头、极端/次极端多空和BRAIN风格六项输出。

- C++负责相关、矩、组合、收益/换手/净值/回撤和衰减；Python组装报告并用SciPy尾概率，仍不创建交易Engine/Runtime。
- Docker镜像 `factorpool/backend:20261109-r2`、`factorpool/frontend:20261109-r2`；保留r1供回退，PostgreSQL与任务目录沿原配置。
- 当前源码摘要和父环境ID见 `docker/build-info.json`，完成任务返回相同manifest。
- 入口保持 [Tailscale](http://master-2019.tailaeed46.ts.net:8088) 和 [当前LAN](http://192.168.1.6:8088)，LAN IP可变。

## 当前限制与回退

PDF没有计算源码与完整数据，部分统计定义需要显式选择，本项目没有复用PDF的历史收益/图表。
BRAIN完整官方模拟指标正文及oracle尚未获得；六项是披露公式的研究预设，不声明官方数值一致。
市值、行业、Self/Production correlation没有合格数据，保持null/--。
raw价格、无费用/无成交约束；月/年组合收益按持有期退出日期归属，不能当成逐日盯市月收益。

回退前停止提交新任务并等待当前队列排空；以原`.env`及状态目录运行：

```bash
FACTORPOOL_RELEASE=20261109-r1 docker compose up -d --no-build --wait
```

结果存储为版本化JSON，r1页面可继续读主一期字段；新报告参数不能由r1执行进程重新运行，恢复r2后再提交。
没有删除状态目录或数据库，不使用`down -v`。
