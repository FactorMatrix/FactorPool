## IC 与显著性

- h期前瞻收益 `P[t+1+h]/P[t+1]-1`；成对有限、在池的因子和严格正入/出价格才参与。
- Pearson IC与同样本的平均并列Spearman Rank IC分别计算；默认至少3对，常量分母或不足为null。
- 均值/标准差只用有效日期；ICIR=均值/标准差，不年化，默认ddof=1。
- 正值比例=有效IC中严格大于0的比例；0是有效观测，不是正值。
- 偏度采用调整Fisher-Pearson，至少3个观测；峰度采用偏差修正的Fisher超额峰度，至少4个观测；常量均不可计算。
- IID t检验为均值/样本标准误，双侧Student-t、df=n-1。h>1的逐日IC含重叠，IID不修正自相关。
- 另给HAC均值t值：Bartlett权重、lag=h-1，长程方差 `gamma0+2*sum((1-k/(L+1))*gammak)`，标准误为sqrt(长程方差/n)，p值为双侧渐近正态。
  只对完整、等距观测计算，缺日期不压缩为相邻；n不足或长程方差不正则null。这个固定lag不是最优带宽或全部序列相关已消除的保证。
- 极小p发生数值下溢时为null并携带underflow状态，不用0冒充精确概率。
- 30期均线要求完整30期；累计IC为求和，缺日期后不伪造完整累计。年/月IC是当期有效观测均值，保留有效/缺失数。
- 衰减固定原因子，依次用未来 `[t+1+k*h,t+1+(k+1)*h]` 价格区间，k=0..steps-1。
  它是本项目明确的预测力衰减定义，PDF未给公式，不能宣称与PDF“阶梯”原算法已对账。

## 组合矩阵与收益

为避免重叠h期收益被当成每日独立收益连乘，组合只在首个因子日期、首日+h、首日+2h...调仓。
当前信号决定权重，T+1开盘进入，h个交易日后开盘退出；缺未来价格不改变原选择或把剩余股票重新归一。

- 组成员仅由当时有效因子决定，升序后按证券轴稳定排序，并列可拆组，floor(k*G/N)分组；空组不可用。
- 各组多头权重和1；空头为对应权重的负数。最高/最低组和次高/次低组两侧分别+0.5/-0.5。
- Alpha预设为在池有效因子截面去算术均值，再按绝对值和归一。常量/全零中心化后不可用，不输出假0收益。
- 持有期归一化PnL `r=sum(w_i*(P_exit/P_entry-1))`；任何非零权重的定价缺失使整个组合区间无效。
- 换手为 `sum(abs(w_new_i-w_old_i*P_entry_new/P_entry_old))`，按前次单位持仓的价格漂移计算，包含首次从0建仓。
  价格读取覆盖原有成员的退出报价，不能因今日已移出池就跳过旧持仓。未来成员不进入因子轴。
- 分组研究仍为无费用理论组合；没有流动性、交易约束、融资成本或真实委托。

收益序列只包含上述非重叠区间。年化系数 A=annual_days/h，默认annual_days=252：
年化均值收益=mean(r)*A，年化波动=sample_std(r)*sqrt(A)，Sharpe=mean/std*sqrt(A)，无风险利率取0。
CAGR=`prod(1+r)^(A/n)-1`，单独显示，不拿CAGR替代Sharpe分子的均值收益。
净值从1复利，最大回撤含初始1的高点；中途缺失或复利资金不正使CAGR/完整净值回撤不可用。
胜率为有效期中严格正收益比例；盈亏比为平均盈利/平均亏损绝对值，无盈利或无亏损时null。
月/年收益按**退出日期**归属后复利，是已完成持有期归属统计，跨月持有并非逐日盯市的自然月收益。

## BRAIN风格六项

使用上述Alpha权重、总gross book=1、资本归一分母0.5，采用固定book的PnL统计：

| 字段 | 本项目研究公式 | 展示 |
| --- | --- | --- |
| Sharpe | mean(r)/sample_std(r) × sqrt(annual_days/h) | 普通比值 |
| Returns | mean(r) × annual_days/h / 0.5 | 百分比；不是CAGR |
| Turnover | sum(调仓换手)/(区间数×h) | 日均百分比；含首次建仓 |
| Drawdown | 累计算术PnL的最大峰谷差/0.5 | 正值百分比；和复利净值回撤分开 |
| Fitness | Sharpe × sqrt(abs(Returns)/max(Turnover,0.125)) | 普通比值 |
| Margin | sum(r)/sum(调仓换手) | bp，即比率×10000 |

固定book累计PnL与回撤有独立曲线；复利净值破产不会被用于伪造固定book回撤。
本预设没有行业中性、衰减、截断等BRAIN任务配置，不能拿本地结果与另一组设置的官方结果直接比较。
Self-correlation、Production correlation、市值与行业暴露没有合格参考数据，输出null/--及原因。
